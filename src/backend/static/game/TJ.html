게임 정보

No More Floor는 제한된 발판 위에서 생존을 이어가는 스릴 넘치는 클릭 기반 아케이드 게임입니다.
플레이어가 바닥을 클릭한다면 7개의 발판 중 일부가 사라지게됩니다!
만일 클릭한 바닥이 사라져 떨어지게 된다면 그대로 Game Over입니다 신중하게 선택하세요!
최대한 떨어지지 않으며 고득점을 노려보세요! 행운을 빕니다!

조작 방법:
  • 마우스 클릭 화면에 표시된 발판을 클릭하여 캐릭터를 해당 위치로 이동합니다.
  • Space 위기 상황에서 한 번만 사용할 수 있는 로켓 기능을 활성화합니다.
    로켓을 사용하면 해당 턴에서 추락하지 않고 생존할 수 있습니다. 단, 한 게임당 한 번만 사용할 수 있으니 신중히 활용하세요!
목표: 사라지는 바닥 위에서 가장 오래 살아남아 최고의 점수를 기록하세요!
